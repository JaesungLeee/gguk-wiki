# 운영 방침

| 항목 | 내용 |
| --- | --- |
| 모델 | ingest 스킬만 `model: opus`로 고정하고, ask 스킬은 `model: inherit`로 세션 모델을 따른다 |
| 비용 | 각자의 개인 구독으로 쓴다. 위키 전용 API 키와 지출 한도는 두지 않는다 |
| 공개 범위 | [공개 범위](data-model.md#공개-범위)를 따른다 |
| 언어 | 위키 본문은 한국어, 코드 용어는 영어 원문 유지. 직역이 아닌 용어만 [용어집](data-model.md#위키-구조)으로 연결 |

**모델**

- ingest는 잘못 추출한 결정이 위키에 오래 남으므로, 세션 모델과 관계없이 Opus로 실행해 품질의 하한을 맞춘다. 조회는 각자 사용량에 맞게 고른다.
- SKILL.md frontmatter의 `model`은 스킬이 실행된 턴에만 적용되고 설정에 저장되지 않는다. 다음 프롬프트부터는 세션 모델로 돌아간다.
- Fable처럼 Opus보다 상위 모델로 세션을 쓰고 있어도 ingest 턴은 Opus로 실행된다.
- 버전 번호 대신 별칭(`opus`, `sonnet`)을 쓴다. 별칭은 최신 버전을 가리키므로 새 모델이 나와도 고칠 필요가 없다.
- Claude Code 전용 설정이다. 다른 도구에서는 각자 고른다([다른 LLM 도구 지원](plugin.md#다른-llm-도구-지원-1단계-확장)).

1단계에서 하지 않는 것은 [1단계 범위](README.md#1단계-범위)를 따른다. 자동 lint, 알림, 검색 기록, 성과 측정의 설계는 [자동화](backlog/automation.md)에 둔다.
