# Claude Code 훅

> 상태: backlog. 미룬 이유는 [backlog/](README.md)를 따른다.

개발자가 묻지 않아도 관련 결정이 작업 컨텍스트에 들어가게 한다. 1단계의 ask 스킬은 사용자가 묻거나 Claude가 필요하다고 판단할 때만 실행되지만, 훅은 Claude의 판단 없이 매번 실행된다.

## 세션 시작 훅

레포에 해당하는 플랫폼([`platforms`](../data-model.md#결정-문서-형식))의 유효한 결정 제목과 요약을 세션 첫머리에 넣는다. 분량이 넘치면 요약을 줄이고, 그래도 넘치면 제목만 넣는다.

```text
[GGUK 위키 · android 관련 유효 결정 12건]
- 환불 기한 (2026-11-10): 결제 후 7일 이내만 환불 가능. 기한 계산은 서버, 클라이언트는 표시만
- 마케팅 푸시 야간 제한 (2026-10-20): 21시~8시 발송 금지
```

- 효과: "주문 상세에 환불 버튼 추가해줘"만 말해도 7일 조건이 반영된다. 바뀐 정책을 모르고 옛 기준으로 구현하는 것을 막는다.
- 구현: CI가 merge 때 `index.md`와 함께 플랫폼별 결정 요약 파일(예: `wiki/_generated/session-android.md`)을 만들고, 훅은 로컬 위키 clone의 이 파일을 출력만 한다. 서버를 도입하면 `GET /hooks/session-start?platform=android`를 호출한다.
- 레포별 플랫폼은 코드 레포 `.claude/settings.json`의 환경 변수 `GGUK_PLATFORM`(`server` | `android` | `ios`)으로 준다.
- 비용과 한계
  - 관련 없는 작업에도 매 세션 토큰을 쓴다.
  - 제목과 요약만 들어가므로 자세한 내용은 따로 조회해야 한다.
  - 로컬 clone이 오래되면 옛 결정이 들어간다.

## 프롬프트 입력 훅

질문마다 위키 검색 결과를 덧붙인다. 짧은 입력과 슬래시 명령은 건너뛴다.

```text
입력: 결제 취소 API 호출부 리팩터링해줘
추가: [관련 위키] wiki/decisions/2026-11-10-환불-기한.md — 결제 후 7일 이내만 환불 가능 …
```

- 효과: 세션 시작 훅에 없는 다른 플랫폼 결정이나 세부 내용이 질문 시점에 붙는다.
- 한계: 훅은 LLM이 아니라 스크립트라서 프롬프트에서 검색어를 기계적으로 뽑아야 한다. 정규화 없이 grep하면 잡음이 붙는다(예: "로그인 화면 버튼 색 바꿔줘" → "버튼"으로 관련 없는 페이지가 붙음). [형태소 분석기 정규화](search-upgrades.md#형태소-분석기-정규화)가 먼저 필요하다.
- 구현: 서버를 도입하면 `/hooks/prompt-search`를 호출한다.

## 공통 규칙

- 훅은 bash와 curl로 쓴다. 개발자 PC에서 실행되므로 Python 버전이나 패키지에 의존하지 않는다.
- 훅이 실패하거나 5초를 넘기면 조용히 통과한다. 위키 조회 때문에 개발 작업이 막히면 안 된다.
- 플러그인에 담아 배포한다. 훅을 레포마다 복사하지 않는다([설치와 배포](../plugin.md#설치와-배포)).
